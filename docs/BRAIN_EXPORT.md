# Brain export

The export retains `knowledge/`, active `hypotheses/`, and negative/historical `archive/`. Deterministic promotion requires qualification, confidence, source diversity, freshness and no unresolved contest; later contradiction or staleness emits an audited demotion.

`summary.md` is diff-oriented: promotions, demotions, qualification changes, contested/stale beliefs, strongest evidence, unresolved priorities, second-order insights, opportunities/venture candidates, world-model updates and research queue counts. Graph JSON and changelog remain machine-readable.
