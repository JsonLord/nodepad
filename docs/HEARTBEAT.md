# Durable heartbeat

Run `npm run heartbeat -- <workspace> --once` or omit `--once` for the durable worker. The leased pipeline performs ingest, identity dedupe, hybrid deterministic theme clustering, scoped family synthesis, hypothesis matching, score passes, falsification-biased gap planning, policy-routed research, classified result ingestion, graph/Gardener maintenance, promotion/demotion, staleness and backup.

Provider runtime enforces enabled/health state, free-first cost ceilings, preferred sources, concurrency, minimum interval, request windows and cooldown. A failed/rate-limited provider is isolated. `CapabilityResearchProvider` proves the adapter boundary for future Reddit/LinkedIn/Idea-Reality/Jina/SearXNG/crawler MCP capabilities without making them dependencies.

Research evidence classification is conservative: unknown external text defaults to stated, third-party evidence. Behavioral/measured, first-party, reliability, source identity, account/person and directness require explicit provider metadata.
